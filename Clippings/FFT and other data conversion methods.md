Ο **Fourier transform** είναι τρόπος να δεις ένα σήμα όχι ως «τιμή που αλλάζει στον χρόνο», αλλά ως **συνδυασμό συχνοτήτων**.

## Η βασική ιδέα

Ένα σήμα μπορεί να φαίνεται πολύπλοκο:

```
χρόνος → τιμή σήματος
```

π.χ. ήχος, σεισμικό κύμα, ηλεκτρικό σήμα, εικόνα, θόρυβος.

Ο Fourier λέει κάτι εντυπωσιακό:

> Κάθε αρκετά «κανονικό» σήμα μπορεί να γραφτεί ως άθροισμα απλών ημιτόνων και συνημιτόνων διαφορετικών συχνοτήτων, πλατών και φάσεων.

Δηλαδή αντί να πεις:

```
το σήμα έχει αυτήν την τιμή στο t=0.1s,
αυτήν στο t=0.2s,
αυτήν στο t=0.3s...
```

λες:

```
περιέχει 50 Hz με τόσο πλάτος,
120 Hz με τόσο πλάτος,
1000 Hz με τόσο πλάτος...
```

Αυτό είναι η μετάβαση από **time domain** σε **frequency domain**.

## Παράδειγμα με ήχο

Αν παίξεις μία καθαρή νότα, π.χ. 440 Hz, το σήμα στον χρόνο είναι ένα σχετικά καθαρό ημίτονο.

Αν όμως παίξεις πιάνο, κιθάρα ή φωνή, το σήμα δεν είναι ένα ημίτονο. Είναι μίγμα:

1. βασικής συχνότητας,
2. αρμονικών,
3. θορύβου,
4. χαρακτηριστικών του οργάνου.

Ο Fourier transform σού λέει:

```
αυτός ο ήχος αποτελείται από αυτές τις συχνότητες,
με αυτά τα πλάτη.
```

Γι’ αυτό χρησιμοποιείται σε audio analyzers, equalizers, συμπίεση ήχου, αναγνώριση φωνής κ.λπ.

## Το μαθηματικό νόημα

Ο συνεχής Fourier transform γράφεται έτσι:

$X(f)=\int_{-\infty}^{\infty}x(t)e^{-i2\pi ft}\,dt$

Με απλά λόγια:

1. Το `x(t)` είναι το αρχικό σήμα στον χρόνο.
2. Το `X(f)` είναι η αναπαράσταση του σήματος ανά συχνότητα.
3. Για κάθε συχνότητα `f`, ο μετασχηματισμός ελέγχει «πόσο μοιάζει» το σήμα με κύμα αυτής της συχνότητας.
4. Αν μοιάζει πολύ, το `X(f)` έχει μεγάλο μέγεθος.
5. Αν δεν υπάρχει τέτοια συχνότητα στο σήμα, το `X(f)` είναι μικρό ή μηδενικό.

Το εκθετικό `e^{-i2πft}` είναι μαθηματικός τρόπος να περιγράψεις περιστρεφόμενο ημίτονο/συνημίτονο. Δεν είναι «μαγικό»· είναι συμπαγής γραφή για ημιτονοειδή κύματα.

## Τι σημαίνει πλάτος και φάση

Το αποτέλεσμα του Fourier transform είναι συνήθως **μιγαδικό**.

Αυτό δεν είναι μειονέκτημα. Περιέχει δύο πληροφορίες:

1. **Magnitude / amplitude**: πόσο έντονη είναι μια συχνότητα.
2. **Phase**: πού βρίσκεται χρονικά το κύμα, δηλαδή η μετατόπισή του.

Για πολλές εφαρμογές, όπως spectrum analyzer, κοιτάμε κυρίως το magnitude.  
Για ανακατασκευή σήματος, συμπίεση ή εικόνες, η φάση είναι κρίσιμη.

## Discrete Fourier Transform

Οι υπολογιστές δεν έχουν συνεχές σήμα. Έχουν δείγματα:

```
x[0], x[1], x[2], ..., x[N-1]
```

Εκεί χρησιμοποιείται η **Discrete Fourier Transform**, δηλαδή DFT.

$X_k=\sum_{n=0}^{N-1}x_n e^{-i2\pi kn/N}$

Η DFT παίρνει `N` δείγματα και υπολογίζει πόση ενέργεια υπάρχει σε `N` διακριτές συχνοτικές θέσεις.

Το πρόβλημα: η απλή DFT είναι αργή.

Για `N` δείγματα θέλει περίπου:

```
N² υπολογισμούς
```

Αν έχεις 1.000.000 δείγματα, αυτό γίνεται πρακτικά βαρύ.

## Τι κάνει ο FFT

Ο **Fast Fourier Transform** δεν είναι διαφορετικός μετασχηματισμός. Είναι γρήγορος αλγόριθμος για να υπολογίσεις την ίδια DFT.

Η κλασική Cooley–Tukey ιδέα είναι:

1. Σπάσε το πρόβλημα σε ζυγούς και μονούς δείκτες.
2. Υπολόγισε μικρότερες DFT.
3. Συνδύασέ τες έξυπνα.
4. Απόφυγε επαναλαμβανόμενους υπολογισμούς.

Έτσι το κόστος πέφτει περίπου από:

```
O(N²)
```

σε:

```
O(N log N)
```

Αυτό είναι τεράστια διαφορά.

Παράδειγμα:

| Δείγματα | DFT περίπου | FFT περίπου |
| --- | --- | --- |
| 1.024 | ~1.048.576 πράξεις | ~10.240 πράξεις |
| 1.000.000 | ~1.000.000.000.000 πράξεις | ~20.000.000 πράξεις |

Οι αριθμοί είναι χονδρικοί, αλλά δείχνουν το μέγεθος της διαφοράς.

## Παράδειγμα με σεισμικά δεδομένα

Αυτό συνδέεται με το άρθρο της IBM.

Ένας σεισμικός αισθητήρας γράφει κίνηση εδάφους στον χρόνο:

```
t=0s     → μικρή κίνηση
t=1s     → μεγαλύτερη κίνηση
t=2s     → άλλη μορφή
...
```

Αν το κοιτάξεις μόνο στον χρόνο, μπορεί να είναι δύσκολο να ξεχωρίσεις αν προέρχεται από:

1. φυσικό σεισμό,
2. υπόγεια έκρηξη,
3. θόρυβο,
4. μηχανικές δονήσεις.

Στο frequency domain όμως μπορεί να φανεί ότι:

```
αυτό το γεγονός έχει ισχυρή ενέργεια σε συγκεκριμένες συχνότητες,
άρα μοιάζει περισσότερο με έκρηξη ή με σεισμό.
```

Άρα ο Fourier transform δεν «μαντεύει». Απλώς σου αλλάζει οπτική γωνία ώστε να δεις χαρακτηριστικά που στον χρόνο κρύβονται.

## Παράδειγμα με εικόνες

Μια εικόνα μπορεί επίσης να θεωρηθεί σήμα, αλλά σε δύο διαστάσεις:

```
x, y → φωτεινότητα
```

Οι χαμηλές συχνότητες αντιστοιχούν σε ομαλές αλλαγές:

```
ουρανός, μεγάλες επιφάνειες, γενικό σχήμα
```

Οι υψηλές συχνότητες αντιστοιχούν σε λεπτομέρειες:

```
άκρα, γράμματα, υφή, θόρυβος
```

Γι’ αυτό ο Fourier transform και συγγενικές τεχνικές χρησιμοποιούνται σε συμπίεση εικόνας, φίλτρα, sharpening, denoising και reconstruction.

## Η ουσία

Ο Fourier transform απαντά στην ερώτηση:

> Από ποιες συχνότητες αποτελείται αυτό το σήμα;

Ο FFT απαντά στην πρακτική ερώτηση:

> Πώς το υπολογίζω αρκετά γρήγορα ώστε να είναι χρήσιμο σε πραγματικό υπολογιστή;

Το παραδοσιακό αλλά σωστό συμπέρασμα είναι ότι ο Fourier transform είναι περισσότερο **αλλαγή βάσης** παρά «ανάλυση ήχου» ή «κόλπο σήματος». Παίρνεις το ίδιο αντικείμενο και το εκφράζεις σε άλλη γλώσσα: από δείγματα στον χρόνο, σε συντελεστές συχνοτήτων.

## 1\. Short-Time Fourier Transform

Η **STFT** είναι Fourier σε μικρά χρονικά παράθυρα.

Αν ο απλός Fourier σου λέει:

> ποιες συχνότητες υπάρχουν συνολικά στο σήμα,

η STFT σου λέει:

> ποιες συχνότητες υπάρχουν και πότε εμφανίζονται.

Χρήσιμη όταν το σήμα αλλάζει με τον χρόνο, π.χ.:

1. ομιλία,
2. μουσική,
3. σεισμικά γεγονότα,
4. μηχανικές δονήσεις,
5. ECG/EEG.

Παράγει συνήθως **spectrogram**.

Το μειονέκτημα είναι κλασικό: αν πάρεις μικρό παράθυρο, έχεις καλή χρονική ανάλυση αλλά κακή συχνοτική. Αν πάρεις μεγάλο παράθυρο, το αντίστροφο.

## 2\. Wavelet Transform

Τα **wavelets** είναι ίσως η πιο φυσική εναλλακτική στον Fourier για μη σταθερά σήματα.

Η βασική διαφορά:

| Μέθοδος | Οπτική |
| --- | --- |
| Fourier | συχνότητες σε όλο το σήμα |
| STFT | συχνότητες ανά σταθερό παράθυρο |
| Wavelets | συχνότητες/κλίμακες με μεταβλητή ανάλυση |

Τα wavelets βλέπουν καλά:

1. απότομα γεγονότα,
2. spikes,
3. αλλαγές καθεστώτος,
4. local patterns,
5. transient phenomena.

Σε σεισμικά δεδομένα, financial series, biomedical signals και fault detection είναι πολύ χρήσιμα.

Παραδοσιακά, είναι πιο «χειροποίητα» και ερμηνεύσιμα από ένα neural network, αλλά θέλουν επιλογή wavelet family.

## 3\. Autocorrelation

Η **αυτοσυσχέτιση** δείχνει πόσο μοιάζει η σειρά με τον εαυτό της αν τη μετατοπίσεις χρονικά.

Απαντά σε ερωτήσεις όπως:

> Υπάρχει περιοδικότητα;  
> Το σημερινό εξαρτάται από το χθεσινό;  
> Κάθε πόσα βήματα επαναλαμβάνεται κάτι;

Παράδειγμα:

```
lag 1   → σχέση με την προηγούμενη τιμή
lag 7   → εβδομαδιαίο μοτίβο
lag 24  → ημερήσιος κύκλος σε hourly data
```

Είναι απλή αλλά δυνατή μέθοδος. Αν δεν κοιτάξεις autocorrelation σε time series, συνήθως πετάς βασική πληροφορία.

## 4\. Partial Autocorrelation

Η **PACF** δείχνει τη συσχέτιση σε συγκεκριμένο lag αφού αφαιρέσεις την επίδραση των ενδιάμεσων lags.

Χρήσιμη κυρίως για AR models.

Παράδειγμα:

Αν το `x[t]` συσχετίζεται με το `x[t-3]`, μπορεί αυτό να συμβαίνει επειδή:

```
x[t] depends on x[t-1],
x[t-1] depends on x[t-2],
x[t-2] depends on x[t-3]
```

Η PACF προσπαθεί να δείξει αν υπάρχει άμεση σχέση με το lag 3 ή απλώς έμμεση.

## 5\. Decomposition

Η αποσύνθεση χρονοσειράς τη σπάει σε μέρη:

```
series = trend + seasonality + residual
```

Δηλαδή:

1. **trend**: γενική κατεύθυνση,
2. **seasonality**: επαναλαμβανόμενα μοτίβα,
3. **residual**: ό,τι μένει.

Χρήσιμες τεχνικές:

1. classical decomposition,
2. STL decomposition,
3. X-13ARIMA-SEATS,
4. Prophet-style decomposition.

Καλή για επιχειρησιακά δεδομένα, πωλήσεις, traffic, μετρήσεις, ενέργεια.

Η αξία της είναι ότι σε αναγκάζει να μη βλέπεις τη σειρά σαν ένα πράγμα.

## 6\. Differencing

Το **differencing** δεν κοιτάζει την ίδια την τιμή, αλλά τη μεταβολή της.

Αν έχεις:

```
x[t]
```

κοιτάς:

```
x[t] - x[t-1]
```

Έτσι αλλάζεις ερώτηση από:

> ποια είναι η τιμή;

σε:

> πόσο άλλαξε;

Είναι πολύ σημαντικό σε σειρές με trend, όπως τιμές μετοχών, θερμοκρασίες, counters, πληθωρισμός, αισθητήρες.

Στα οικονομικά δεδομένα συνήθως δεν κοιτάς την τιμή, αλλά returns/log-returns.

## 7\. Rolling statistics

Εδώ κοιτάς στατιστικά σε κινούμενο παράθυρο:

1. moving average,
2. rolling variance,
3. rolling standard deviation,
4. rolling median,
5. rolling quantiles,
6. rolling min/max,
7. rolling z-score.

Αλλάζει την οπτική από μεμονωμένες τιμές σε τοπική συμπεριφορά.

Π.χ. σε trading:

```
η τιμή ανέβηκε
```

είναι λιγότερο χρήσιμο από:

```
η τιμή ανέβηκε ενώ η μεταβλητότητα αυξήθηκε και βρίσκεται 2.5σ πάνω από τον μέσο όρο
```

## 8\. State-space models

Τα **state-space models** υποθέτουν ότι υπάρχει μια κρυφή κατάσταση πίσω από τις μετρήσεις.

Παράδειγμα:

```
observed value = noisy measurement of hidden state
```

Κλασικό εργαλείο:

1. Kalman Filter,
2. Extended Kalman Filter,
3. Unscented Kalman Filter,
4. Particle Filter.

Αυτό είναι πολύ χρήσιμο όταν έχεις θόρυβο και θες να εκτιμήσεις την πραγματική κατάσταση ενός συστήματος.

Παραδείγματα:

1. tracking θέσης,
2. αισθητήρες,
3. navigation,
4. robotics,
5. οικονομικά latent factors,
6. physiological signals.

Η οπτική εδώ είναι:

> όχι τι μετράω, αλλά ποια πραγματική κατάσταση παρήγαγε αυτή τη μέτρηση.

## 9\. Hidden Markov Models

Τα **HMMs** βλέπουν τη χρονοσειρά ως αποτέλεσμα κρυφών διακριτών καταστάσεων.

Παράδειγμα σε αγορά:

```
state 1: bullish low volatility
state 2: bearish high volatility
state 3: sideways
```

Οι παρατηρήσεις είναι οι τιμές/returns, αλλά το μοντέλο προσπαθεί να βρει το πιθανό κρυφό regime.

Χρήσιμο για:

1. regime detection,
2. speech recognition,
3. bioinformatics,
4. fault detection,
5. market states.

Πιο ερμηνεύσιμο από deep learning, αλλά πιο περιορισμένο.

## 10\. Recurrence plots

Τα **recurrence plots** δείχνουν πότε το σύστημα επιστρέφει σε παρόμοιες καταστάσεις.

Αντί να κοιτάς τη σειρά ως γραμμή, φτιάχνεις έναν πίνακα που λέει:

```
η κατάσταση στη στιγμή i μοιάζει με την κατάσταση στη στιγμή j;
```

Χρήσιμο για μη γραμμικά ή χαοτικά συστήματα.

Μπορεί να αποκαλύψει:

1. επαναλήψεις,
2. μεταβάσεις,
3. περιοδικότητα,
4. μη στασιμότητα,
5. αλλαγή δυναμικής.

Είναι λιγότερο mainstream, αλλά σε σωστά δεδομένα δίνει οπτική που ο Fourier δεν πιάνει καλά.

## 11\. Phase-space reconstruction

Εδώ παίρνεις μια απλή χρονοσειρά και φτιάχνεις διανύσματα με καθυστερήσεις:

```
[x(t), x(t-τ), x(t-2τ), ...]
```

Έτσι προσπαθείς να ανακατασκευάσεις τη δυναμική του συστήματος.

Χρήσιμο σε:

1. nonlinear dynamics,
2. chaos analysis,
3. attractors,
4. anomaly detection,
5. complex physical systems.

Η φιλοσοφία είναι βαθιά: από μία μόνο παρατηρούμενη μεταβλητή προσπαθείς να δεις τη γεωμετρία του συστήματος που την παράγει.

## 12\. Matrix profile

Το **Matrix Profile** είναι εξαιρετικά πρακτική τεχνική για εύρεση επαναλαμβανόμενων μοτίβων και ανωμαλιών σε χρονοσειρές.

Απαντά σε ερωτήσεις όπως:

1. ποιο subsequence επαναλαμβάνεται πιο συχνά;
2. ποιο κομμάτι είναι πιο ασυνήθιστο;
3. υπάρχουν motifs;
4. υπάρχουν discords/anomalies;

Είναι πολύ χρήσιμο όταν δεν ξέρεις από πριν τι ψάχνεις.

Σε αντίθεση με Fourier/wavelets, δεν ξεκινά από συχνότητες. Ξεκινά από τοπικά σχήματα.

## 13\. Dynamic Time Warping

Το **DTW** συγκρίνει δύο χρονικές σειρές ακόμα κι αν είναι χρονικά τεντωμένες ή συμπιεσμένες.

Παράδειγμα:

```
δύο κινήσεις μοιάζουν,
αλλά η μία έγινε πιο γρήγορα από την άλλη
```

Το απλό Euclidean distance μπορεί να πει ότι είναι διαφορετικές. Το DTW μπορεί να πει ότι είναι παρόμοιες.

Χρήσιμο για:

1. gesture recognition,
2. speech,
3. pattern matching,
4. βιοσήματα,
5. machine vibration signatures.

Το μειονέκτημα είναι ότι μπορεί να είναι υπολογιστικά βαρύ και θέλει προσοχή για να μη βρει ψευδείς ομοιότητες.

## 14\. Change point detection

Εδώ δεν ρωτάς «ποια είναι η συχνότητα;», αλλά:

> πότε άλλαξε η συμπεριφορά της σειράς;

Μπορεί να ανιχνεύσει αλλαγές σε:

1. mean,
2. variance,
3. trend,
4. distribution,
5. correlation structure.

Χρήσιμο για:

1. monitoring συστημάτων,
2. οικονομικά regimes,
3. industrial faults,
4. logs,
5. βιοϊατρικά σήματα.

Είναι από τις πιο χρήσιμες πρακτικές μεθόδους για πραγματικά δεδομένα.

## 15\. Entropy measures

Η εντροπία κοιτάζει πόσο προβλέψιμη ή ακανόνιστη είναι μια σειρά.

Μέθοδοι:

1. Shannon entropy,
2. Approximate entropy,
3. Sample entropy,
4. Permutation entropy.

Αλλάζει την οπτική από «τι τιμές έχει» σε:

> πόσο δομημένη ή τυχαία είναι;

Χρήσιμο σε ECG/EEG, μηχανικά συστήματα, οικονομικά δεδομένα, anomaly detection.

## 16\. Symbolic representations

Μετατρέπεις αριθμητική σειρά σε σύμβολα.

Παράδειγμα:

```
τιμή πάνω από μέσο → A
τιμή κοντά στον μέσο → B
τιμή κάτω από μέσο → C
```

Ή πιο τυπικά:

1. SAX,
2. Symbolic Fourier Approximation,
3. ordinal patterns.

Μετά μπορείς να χρησιμοποιήσεις τεχνικές από text mining, pattern matching, indexing.

Καλή μέθοδος όταν έχεις τεράστιες σειρές και θες απλοποίηση.

## 17\. ARIMA και statistical forecasting models

Τα ARIMA/SARIMA βλέπουν τη σειρά μέσα από:

1. autoregression,
2. differencing,
3. moving average errors,
4. seasonality.

Δεν είναι απλώς πρόβλεψη. Είναι τρόπος να περιγράψεις τη δομή εξάρτησης της σειράς.

Παραδοσιακή, σοβαρή μέθοδος. Όχι «μοντέρνα», αλλά ακόμα πολύ χρήσιμη όταν τα δεδομένα είναι σχετικά καθαρά και θες ερμηνεία.

## 18\. Neural embeddings

Με μοντέλα όπως:

1. autoencoders,
2. sequence transformers,
3. temporal CNNs,
4. contrastive learning,
5. recurrent models,

μπορείς να μετατρέψεις μια χρονοσειρά ή subsequence σε embedding vector.

Η νέα οπτική είναι:

> παρόμοια χρονικά μοτίβα βρίσκονται κοντά στον χώρο embeddings.

Χρήσιμο για clustering, search, anomaly detection, classification.

Το μειονέκτημα: λιγότερη ερμηνευσιμότητα. Αν δεν έχεις πολύ data ή σωστό validation, εύκολα φτιάχνεις εντυπωσιακό αλλά άχρηστο μοντέλο.

| Πρόβλεψη | ARIMA, state-space, ML/deep learning |

## Για σειριακά χρονικά δεδομένα γενικά

Αν είχα να ξεκινήσω πρακτικά, η σειρά προτεραιότητας θα ήταν:

1. **plot + rolling mean/variance**,
2. **autocorrelation/PACF**,
3. **decomposition σε trend/seasonality/residual**,
4. **FFT ή STFT**,
5. **wavelets αν υπάρχουν απότομα/local φαινόμενα**,
6. **change point detection**,
7. **matrix profile για motifs/anomalies**,
8. **state-space/HMM αν υποψιάζεσαι hidden regimes**.

Το βασικό συμπέρασμα:  
ο Fourier σου δίνει τη συχνοτική γλώσσα του σήματος. Τα wavelets σου δίνουν χρόνο και κλίμακα. Η autocorrelation σου δίνει μνήμη. Η decomposition σου δίνει δομή. Τα state-space models σου δίνουν κρυφή κατάσταση. Το matrix profile σου δίνει επαναλαμβανόμενα σχήματα. Αυτές είναι διαφορετικές «γλώσσες» για το ίδιο χρονικό φαινόμενο.
