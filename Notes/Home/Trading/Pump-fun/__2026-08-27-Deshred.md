# 17. Τι μάθαμε συνολικά
Η πιο σημαντική εικόνα είναι:
**1.** Υπήρχε signal ήδη από πολύ νωρίς, ακόμη και 30–50ms.
​
**2.** Creator/external-buyer/concentration features φαίνεται να έχουν πληροφορία.
​
**3.** Η trajectory μετά το Stage2 προσθέτει πολύ περισσότερη πληροφορία.
​
**4.** Τα μεγάλα ideal-replay κέρδη κατέρρεαν συχνά όταν βάζαμε πραγματικό execution delay.
​
**5.** Τα ίδια rules μπορούν να πάνε εξαιρετικά σε ένα δίωρο και αρνητικά στο επόμενο → ισχυρό regime/drift effect.
​
**6.** Άρα το νέο μοντέλο δεν πρέπει να μάθει απλώς «ποιο mint ανεβαίνει», αλλά:
> **με τα δεδομένα που έχω μέχρι τώρα, αξίζει να SEND τώρα ώστε όταν η συναλλαγή εκτελεστεί στο επόμενο slot να παραμένει οικονομικά καλή;**
