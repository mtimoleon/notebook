## Notes
Για την υποβολή ενός ιδιωτικού συμφωνητικού ψηφιακά, θα χρειαστείτε τα εξής: 
- [ ] Τους προσωπικούς σας κωδικούς web banking ή τους προσωπικούς σας κωδικούς πρόσβασης στο Taxisnet (αφού πρώτα εγγραφείτε στο Εθνικό Μητρώο Επικοινωνίας (ΕΜΕπ) για να επιβεβαιώσετε τον αριθμό του κινητού σας τηλεφώνου). 
- [ ] Το κινητό σας τηλέφωνο, όπου θα σας αποσταλούν κωδικοί επιβεβαίωσης πριν την έκδοση του εγγράφου.
- [ ] Τον ΑΦΜ και τα ονοματεπώνυμα των εκδοτών που θα συνυπογράψουν το έγγραφο. 
- [ ] Το έγγραφο που επιθυμείτε να βεβαιώσετε ηλεκτρονικά σε μορφή .pdf. 


Η διαδικασία περιλαμβάνει την ανάρτηση του ιδιωτικού συμφωνητικού που θέλετε να βεβαιώσετε ψηφιακά. Μπορείτε να επιλέξετε αν η ψηφιακή βεβαίωση θα είναι στα ελληνικά ή στα αγγλικά. Μετά την ολοκλήρωση της διαδικασίας από όλους τους συμβαλλόμενους, το υπογεγραμμένο έγγραφο θα εμφανιστεί ψηφιακά βεβαιωμένο στη Θυρίδα πολίτη κάθε υπογράφοντα. Για περισσότερες πληροφορίες, μπορείτε να επισκεφθείτε την επίσημη σελίδα της υπηρεσίας: 
Πηγή: [Σύνδεσμος](https://dilosi.services.gov.gr/templates/IDIOTIKO-SYMFONITIKO/create)
